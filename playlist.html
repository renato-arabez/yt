Salvar / restaurar progresso

O JSON inclui canais, vídeos, histórico, filtros e configurações. A importação faz merge por ID, preservando o que já existe no navegador.

Sincronização com GitHub Gist

O Gist é privado por padrão. O token fica somente neste navegador e nunca é enviado para o conteúdo do Gist.
A API do GitHub exige autenticação para criar/alterar Gists; um token refinado com permissão Gists: write é suficiente. A leitura de um Gist específico não exige permissões adicionais.

Sobre a cota

A aplicação mostra uma estimativa antes da consulta e um contador real durante a consulta. Consultas de reprodução não usam a YouTube Data API. A API só é usada para descobrir/atualizar metadados.
Sistema local. Progresso persistido no LocalStorage. Versão identificada por data/hora.
